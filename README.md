# Overview

This project presents an interactive Book Store Dashboard created using Power BI and DAX to analyze book orders, genres, formats, and publisher distribution. The dashboard provides a clear view of reading trends, top checked-out books, and quarterly performance.

# Tools Used

-Power BI

-DAX

-Data Modeling

-Interactive Visualizations

# Key Insights

-Quarterly ordered books analysis

-Most popular book genres and formats

-Top 10 checked-out books

-Publisher distribution

- Marketing spend overview
